# howtobe

Пачатковы каркас асабістага сайта на Astro. Пакуль сайт складаецца з адной старонкі; кантэнт і астатнюю структуру дадаём паступова.

## Запуск лакальна

Патрэбны Node.js версіі `22.23.4` або навейшай.

```sh
npm install
npm run dev
```

Astro запусціць лакальны сервер, звычайна на <http://localhost:4321>.

## Асноўны файл

- `src/pages/index.astro` — галоўная старонка па адрасе `/`. Файлы ў `src/pages/` вызначаюць URL-адрасы сайта.
- `package.json` — назва праекта, залежнасці і каманды `dev`, `build`, `preview`.
- `astro.config.mjs` — налады Astro. Пакуль выкарыстоўваюцца стандартныя налады.

У файле `.astro` блок паміж `---` — код, які выконваецца на этапе зборкі. HTML пасля блока становіцца старонкай. Тэг `<style>` у гэтым файле дадае стылі толькі для гэтай старонкі.

## Праверка зборкі

```sh
npm run build
npm run preview
```

Зборка стварае гатовыя статычныя файлы ў `dist/`.

## Публікацыя

Код сайта знаходзіцца ў гэтым рэпазіторыі. Адрас `https://jathpr.github.io/` абслугоўвае асобны рэпазіторый `jathpr.github.io`; яго workflow збірае апошні `main` гэтага праекта.

Пасля змен у `main` запусці workflow **Deploy personal site** у рэпазіторыі `jathpr.github.io` праз GitHub Actions → **Run workflow**. Абнаўленне публікуецца на галоўным адрасе карыстальніцкага сайта.
